# Codex Launcher v2.2.0

## Highlights

- 新增 Daily、Weekly、Monthly、Interval、登录、启动及高级 Cron 触发器。
- 新增运行来源标识，可区分 GUI、Windows Scheduled Task 与 Headless CLI。
- 新增定时任务健康面板，集中展示注册状态、最近运行、下次运行与异常信息。

## Improvements

- 配置升级到 V2，并自动迁移与备份旧版 `dailyAt` 配置。
- 定时任务使用 managed state 与 ownership 校验，改名、更新和卸载清理更安全。
- 定时任务与手动运行共用重试、通知和保活主流程，同时保留各自运行来源。
- 高级触发器编辑器采用 shadcn 组件，并修复弹出层 semantic color token 缺失导致的透明重叠问题。

## Quality gates

- Rust formatting、Clippy 与完整测试套件。
- Frontend lint、测试、TypeScript typecheck 与 Vite production build。
- Windows NSIS/MSI bundle 构建与 SHA-256 校验和生成。
